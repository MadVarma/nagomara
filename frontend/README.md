# EC Footwear E-Commerce Platform (Frontend)

## Features
- User authentication (login/register)
- Admin authentication (login/register)
- Product search and display
- Cart and checkout
- Admin product management

## Setup
1. Copy `.env.example` to `.env.local` and set the API URL if needed.
2. Install dependencies:
   ```sh
   cd frontend
   npm install
   ```
3. Start the frontend:
   ```sh
   npm run dev
   ```

## Pages
- `/` — Home, product search/list
- `/login` — User/Admin login
- `/register` — User/Admin register
- `/admin` — Admin dashboard (add/edit/delete products)
- `/cart` — User cart
- `/orders` — User orders
