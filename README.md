# EC Footwear E-Commerce Platform

A full-stack e-commerce footwear web application with admin and user flows, built with Node.js (Express), Next.js (React), and Supabase (PostgreSQL).

## Structure
- `backend/` — Node.js/Express API, JWT auth, Supabase integration
- `frontend/` — Next.js React app, admin/user flows, product search, cart, checkout

## Quick Start
1. See `backend/README.md` for backend setup
2. See `frontend/README.md` for frontend setup

---

All code is modern, clean, and stable. See each folder for details and requirements.
